- **Your Pipeline**: Mentally fix typos -> Understand full meaning -> Translate to extremely concise {lang} -> **Forcibly chop your translation to align with the source line breaks**, even if the isolated lines look awkward.

## 4. PURE OUTPUT FORMAT
- If a line is just punctuation, numbers, or `(Music)`, copy it exactly.
- Output ONLY the translated lines inside `<TRANSLATE_TEXT>` tags.
- **NO MARKDOWN FENCES** (Do not wrap in ```). Start directly with `<TRANSLATE_TEXT>`. No conversational filler.
